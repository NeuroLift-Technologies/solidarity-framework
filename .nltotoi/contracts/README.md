# Governance contract discovery

[NeuroLift Technologies' public governance contract](../../GOVERNANCE.md) governs contributors working in this repository. The machine-readable governance contract lives in the organization's [`.github` repository](https://github.com/NeuroLift-Technologies/.github). [nltotoi.json](../../nltotoi.json) records the upstream revision used for local template imports.

Follow the upstream amendment process for changes to the organization contract. [ADR-001](../../docs/ADR-001.md) records architecture for the Solidarity Framework.
