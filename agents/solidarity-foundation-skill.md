# Solidarity Foundation Skill

Follow [repository governance](../GOVERNANCE.md) and ORG-DEV-OTOI-1.0.4.

## Four pillars

| Pillar | Role |
|---|---|
| Terms of Interaction (TOI) | Carries the person's declared requirements and authority constraints. Defines the canonical format, generator and signing primitives. |
| Orchestrated Terms of Interaction (OTOI) | Resolves trusted TOI at runtime and decides policy, delegation, outbound release, retention, purge and direct governance notices. |
| RRT AIdvocAIte | Provides protective response. The RED/BLACK design keeps bounded direct support available independently in the current interaction. |
| Sleepwalker Protocol | Independently assures continuity against OTOI-resolved requirements. |

## Integration

The State Detection Layer (SDL) supplies advisory observations. The Agent Solidarity Framework Deployment Kit (ASFDK) integrates component interfaces. The ASFDK Harness applies OTOI decisions at supported runtime boundaries. Use the [architecture guide](../docs/unified_architecture.md) for sources and the evidence required for enforcement claims.

For installation and runtime APIs, follow the [ASFDK repository](https://github.com/NeuroLift-Technologies/asfdk) and the applicable component releases. Record the adapter, operation and version when reporting enforcement. Preserve direct protective support, apply the framework's persistence boundary, and escalate architecture, deployment, external integration or threshold changes to Joshua W. Dorsey, Sr.

See the [OTOI skill](nlt-otoi-skill.md), [RRT AIdvocAIte skill](rrt-advocate-skill.md) and [Sleepwalker skill](sleepwalker-skill.md) for component guidance.
